# 🇹🇭 Tax-Planner (2569 / 2026)

โปรแกรมคำนวณและวางแผนภาษีเงินได้บุคคลธรรมดา (ภ.ง.ด. 90/91) ประจำปีภาษี 2569 (2026) 
ออกแบบมาเพื่อให้คนทั่วไปใช้งานได้ง่ายที่สุด รวดเร็ว และเป็นส่วนตัว 100%

## ✨ จุดเด่น (Key Features)

1. **เลือกช่วงเวลาทำงานง่ายๆ:** มี Dropdown เลือกเดือนเริ่มทำงาน ถึง สิ้นสุดงาน (ม.ค. - ธ.ค.) รองรับคนเปลี่ยนงานระหว่างปี
2. **รองรับการปรับเงินเดือน:** เพียงกด `+ เพิ่มการปรับเงินเดือน` เลือกว่าปรับตั้งแต่เดือนไหนและใส่เงินเดือนใหม่ ระบบจะสร้างแถบ Timeline และคำนวณ PVD สะสม + ประกันสังคมตามสเต็ปจริงให้อัตโนมัติ
3. **สรุปผลแบบเรียลไทม์:** เห็นทันทีว่าได้เงินคืนภาษี หรือต้องชำระเพิ่ม พร้อมแถบขั้นบันไดภาษี
4. **จำลองลดหย่อนเพิ่ม (What-If Simulator):** มีแถบเลื่อนจำลองการซื้อ RMF / Thai ESG เพื่อดูว่าได้ภาษีคืนเพิ่มเท่าไรทันที
5. **ความเป็นส่วนตัว 100%:** ข้อมูลทั้งหมดถูกประมวลผลและบันทึกอยู่บนเบราว์เซอร์ของผู้ใช้ (LocalStorage) ไม่มีส่งออกภายนอก

## 🚀 เริ่มต้นใช้งาน (Getting Started)

```bash
# ติดตั้ง dependencies
npm install

# รันโหมด Development
npm run dev

# รัน Unit Tests (Vitest)
npm run test

# Build สำหรับ Production
npm run build
```

## 🏗️ สถาปัตยกรรม (Architecture)

โปรเจกต์นี้แยก Pure Logic และ UI ออกจากกันอย่างเข้มงวดตามหลัก AODD & Project Blueprint:
- `src/config/`: กฎเกณฑ์และอัตราภาษี 2569
- `src/logic/`: Pure functions คำนวณเงินเดือน ภาษี และลดหย่อน (ไม่มี UI/DOM ผสม)
- `src/ui/`: Components แสดงผล
- `tests/`: Vitest ครอบคลุมฟังก์ชันคำนวณทั้งหมด
